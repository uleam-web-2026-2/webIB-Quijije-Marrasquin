## 🛠️ Requisitos Previos
* Node.js LTS instalado (v22+ recomendado).
* Git configurado.
* VS Code recomendado.

## 🚀 Instrucciones para levantar el proyecto
1. Clona este repositorio:
   ```bash
   git clone https://github.com/uleam-web-2026-2/webIB-Quijije-Marrasquin.git
   cd webIB-Quijije-Marrasquin
   ```
2. Instala dependencias:
   ```bash
   npm install
   ```
3. Ejecuta la aplicación en desarrollo:
   ```bash
   npm run dev -- --host 0.0.0.0
   ```
4. Compila para producción:
   ```bash
   npm run build
   ```
